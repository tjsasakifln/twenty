# CONFENGE Operational Management Center

This branch publishes the technical customization used by CONFENGE on top of
[Twenty](https://github.com/twentyhq/twenty) v2.45.0. The customization is kept
under [`confenge-ops/`](confenge-ops/) and consists of deployment configuration,
read-only source adapters, health checks, and offline tests. The upstream
application source remains unchanged.

The running center is available at
[gestao.confenge.com.br](https://gestao.confenge.com.br) and requires an
authorized account. No operational records, customer data, credentials,
production evidence, or private infrastructure details are stored in this
public fork.

For the original Twenty project documentation at this pinned base, see
[`README.upstream.md`](README.upstream.md). Twenty's upstream license and notices
remain in the repository.
